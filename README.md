# Workshop Registration Form

A responsive registration form for a fictional workshop, built as part of the
[freeCodeCamp Responsive Web Design](https://www.freecodecamp.org/learn/responsive-web-design-v9/)
certification curriculum.

## Project Overview

This project demonstrates core HTML form design and CSS styling techniques,
including accessible markup, responsive layout, and user-friendly form UX.

## Live Demo

[View on GitHub Pages](https://YOUR-USERNAME.github.io/workshop-registration-form)

## Built With

- HTML5 — semantic form elements (`<fieldset>`, `<legend>`, `<label>`)
- CSS3 — Flexbox, custom properties, responsive units

## Features

- Accessible form with proper label/input associations
- Responsive layout that works on mobile and desktop
- Input validation using HTML5 attributes (`required`, `type`, `minlength`)
- Clean, readable visual hierarchy
